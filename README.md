# TimorGAPAgent | Multi-Agent Collaboration Platform H5 Demo

This is an interactive H5 demo page based on HTML5 and ECharts, showcasing the multi-agent collaboration capabilities of **TimorGAPAgent** in oil and gas digitalization scenarios.

## Core Features
- **Real-time Monitoring**: Dynamic display of wellbore condition data (Sensor Data Layer).
- **Multi-Agent Collaboration**: Visualization of interaction chains and reasoning (Collaboration Layer).
- **AI Chat Support**: Simulated AI assistant for root cause analysis and operational queries.
- **Deep Diagnostics**: Secondary pages for deep-diving into individual wellbore health and agent reasoning logs.
- **Closed-loop Optimization**: Simulate emergency intervention and automated strategy adjustment.

## Quick Start
1. Open [index.html](index.html) in any mobile browser or desktop browser with mobile simulation enabled.
2. Click **"Anomaly Spike"** to trigger a simulation.
3. Click **"Execute Collab"** to restore balance.
4. Interact with cards or the chat bubble to explore deeper layers.
